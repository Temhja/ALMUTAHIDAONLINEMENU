كيفية إضافة الصور / How to add images:
-----------------------------------------
اسم الملف = رقم المنتج + .jpg
File name  = product ID + .jpg

مثال / Example:
  1.jpg   → تخمير كنتاكي  (Kentucky Marinade)
  2.jpg   → قرمشة          (Crispy Coating)
  3.jpg   → زنجر           (Zinger)
  ... etc

الصيغ المدعومة / Supported formats:
  .jpg  .jpeg  .png  .webp

الحجم الموصى به / Recommended size:
  400 × 400 px minimum
  Square images work best
